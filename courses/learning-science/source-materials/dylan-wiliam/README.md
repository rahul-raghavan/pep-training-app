# Curated Dylan Wiliam Presentations for Learning Science PD

This folder contains the Dylan Wiliam presentations I would review first for building the teacher training sequence and the printable manual. I selected 19 decks from the larger presentation archive.

The selection criteria were:

- Direct relevance to the training program: learning science, formative assessment, feedback, metacognition, responsive teaching, and teacher professional learning.
- High signal: decks that appear to synthesize a major idea rather than only serving a narrow local event.
- Recency where useful: newer workshop versions are often more complete, especially for learning and memory, cognitive load, feedback, and self-regulated learning.
- Practical transfer: decks that can produce teacher-facing activities, examples, discussion prompts, or LMS assessment items.
- Coverage of implementation: not just "what teachers should know", but how a school can help teachers actually change practice over time.

The copied files are original `.pptx` decks from the archive, renamed with short thematic titles. The folder structure is thematic so you can review the decks in roughly the same sequence as the proposed professional development program.

Each deck now has a matching `- Narrative.md` companion file in the same folder. Use those narrative files first when deciding whether a deck belongs in a workshop, LMS module, or manual chapter. They explain the through-line of each deck, the most important slides, and how to use the deck with teachers.

## Recommended Review Order

Use this order if you are building the workshop, LMS modules, and manual in parallel.

1. Motivation and purpose
   - Start with teacher quality and why formative assessment.
   - Goal: create urgency without blaming teachers.
   - Key message: improving teaching is hard, but it is possible when practice is specific, sustained, collaborative, and evidence-informed.

2. Learning science foundations
   - Move to learning and memory before classroom strategies.
   - Goal: teachers should understand why retrieval, spacing, high success rates, explicit modelling, checking for understanding, and feedback matter.
   - Key message: the classroom task is not just to create activity or performance, but durable, transferable learning.

3. Cognitive load and instruction
   - Treat cognitive load as a bridge between learning science and lesson design.
   - Goal: teachers should see why "small steps", modelling, worked examples, scaffolds, guided practice, and gradual release are learning-science moves rather than old-fashioned teacher talk.
   - Key message: novices need different support from experts.

4. Formative assessment and responsive teaching
   - Use Wiliam's formative assessment work as the practical spine of the whole program.
   - Goal: teachers should learn to design lessons around evidence of learning.
   - Key message: formative assessment is not a type of test; it is a process for adapting teaching and learning while there is still time to act.

5. Learning intentions, success criteria, questioning, and evidence
   - Break formative assessment into concrete classroom routines.
   - Goal: teachers should be able to plan evidence-rich lessons.
   - Key message: if the teacher cannot see what students are thinking, the teacher cannot respond intelligently.

6. Feedback, metacognition, and student ownership
   - Move from teacher decisions to student decisions.
   - Goal: teachers should design feedback and classroom routines that make students think, monitor, revise, and regulate.
   - Key message: feedback is only useful if it changes what the learner does next.

7. Research use and implementation
   - Close with how teachers and leaders keep improving after the first workshops.
   - Goal: create a professional development model that survives beyond the launch.
   - Key message: teacher learning requires habits, structures, peer accountability, and cycles of disciplined experimentation.

|---|---|---|
| `01 - Teacher Expertise Is the Improvement Lever.pptx` | A concise deck on teacher quality and the leverage of improving teaching. | `02 - Why Formative Assessment Matters.pptx` | A strong workshop-style rationale for embedding formative assessment. - Slides that distinguish teaching activity from evidence of learning.

### 02_learning_memory_and_cognitive_load

Use these for the learning science module. These are the closest Wiliam-aligned equivalents to the science-oriented chapters of `The Math Academy Way`.

| Deck | Why It Is Impactful | Best Use |
|---|---|---|
| `01 - Cognitive Load Theory in Practice.pptx` | A focused cognitive load deck. Useful if you want a clean, separate treatment of intrinsic load, extraneous load, worked examples, prior knowledge, and novice/expert differences. | Cognitive load chapter; Rosenshine alignment; examples of reducing unnecessary load. |
| `02 - Learning Memory and Retrieval.pptx` | The strongest all-purpose learning and memory deck in this set. It appears to cover learning vs performance, memory, retrieval, cognitive load, metacognition, and practical implications for teaching. | Core LMS module on learning science; manual chapters on memory, practice, retrieval, and durable learning. |
| `03 - Designing for Durable Learning.pptx` | A recent and compact synthesis of cognitive load theory plus learning and memory. Useful because it likely combines the conceptual model with classroom implications. | Refining the cognitive load and lesson design chapter; teacher-facing summaries. |

Suggested extraction:

- Learning vs performance: why fluency in the moment is not enough.
- Working memory limits and long-term memory as the basis of expertise.
- Cognitive load: intrinsic, extraneous, and germane load if those distinctions are present.
- Novice vs expert differences.
- Retrieval practice, spacing, interleaving, and practice quality.
- Connections to Rosenshine: daily review, small steps, modelling, guided practice, checking understanding, high success rates, independent practice, and weekly/monthly review.

Where this aligns with `The Math Academy Way`:

- Use these decks alongside the Math Academy chapters on active learning, deliberate practice, mastery learning, cognitive load, automaticity, spacing, interleaving, retrieval practice, and targeted remediation.
- The common thread is that learning is a change in long-term memory, not just participation, explanation, or short-term task success.
- The practical implication is that lesson design should manage cognitive load and build durable retrieval strength over time.

### 03_formative_assessment_core

Use these as the spine of the whole program. Wiliam's formative assessment work is the natural bridge between learning science and everyday classroom decisions.

| Deck | Why It Is Impactful | Best Use |
|---|---|---|
| `01 - Learning Intentions and Useful Feedback.pptx` | A focused deck on learning intentions, success criteria, and feedback. This is useful because teachers often need these separated from the broader EFA theory. | Manual chapter on clarity; activities on improving learning intentions and success criteria. |
| `02 - Responsive Teaching in Action.pptx` | A practical bridge from assessment to instructional decision-making. Responsive teaching is the language most likely to help teachers see formative assessment as part of normal lesson flow. | Workshop 2; LMS module on using evidence during instruction; lesson planning templates. |
| `03 - Formative Assessment Full Course.pptx` | The most comprehensive formative assessment course deck in the curated folder. Use this as the main source for the five key strategies and the overall EFA architecture. | Core formative assessment module; manual chapters on responsive teaching, learning intentions, eliciting evidence, feedback, and peer/self-assessment. |
| `04 - EFA Plus Practical Synthesis.pptx` | A recent, high-value synthesis of EFA+. It overlaps with the full course deck but likely has updated workshop materials and integrated examples. | Updated examples; facilitator activities; replacement slides where the full course feels too long. |

Suggested extraction:

- The five key strategies of formative assessment.
- The three agents: teacher, peer, and learner.
- Learning intentions and success criteria.
- Evidence elicitation: questions, tasks, hinge points, exit tickets, mini-whiteboards, all-student response.
- Responsive action: what a teacher does after evidence is collected.
- Peer and self-assessment as learning routines, not grading rituals.

Where this aligns with Rosenshine:

- "Ask a large number of questions" maps to eliciting evidence.
- "Check for understanding" maps to responsive teaching.
- "Obtain a high success rate" maps to using evidence to adjust challenge.
- "Provide scaffolds" and "guide student practice" map to acting on evidence before independent practice.

### 04_feedback_metacognition_and_student_ownership

Use these after teachers understand formative assessment. This section answers: once we have evidence, how do we help students use it?

| Deck | Why It Is Impactful | Best Use |
|---|---|---|
| `01 - Eliciting Evidence of Thinking.pptx` | A focused deck on eliciting evidence. Useful for turning the broad idea of formative assessment into concrete teacher moves. | Questioning module; evidence collection routines; hinge-question design practice. |
| `02 - Better Questioning for Better Learning.pptx` | A focused questioning deck. Questioning is one of the highest-leverage classroom techniques because it reveals student thinking and drives retrieval. | Questioning workshop; LMS assessment on question design; teacher practice routines. |
| `03 - Metacognition and Self-Regulation.pptx` | A focused metacognition deck. This supports the move from teacher-regulated learning to student-regulated learning. | Metacognition module; student reflection routines; manual chapter on self-monitoring. |
| `04 - Feedback That Moves Learning Forward.pptx` | The strongest focused feedback deck. Use it to anchor the message that feedback should improve learning by changing student action. | Feedback module; manual chapter on feedback; examples/non-examples. |
| `05 - Feedback Revisited and Refined.pptx` | A shorter updated feedback deck. Useful if the main feedback deck is too long or if you want a second pass with refined language. | Concise feedback review; facilitator notes; optional reinforcement module. |
| `06 - EFA Feedback and Self-Regulation.pptx` | The best integrated capstone across formative assessment, feedback, and self-regulated learning. It is likely one of the most useful decks for designing the later part of the program. | Capstone module; final live workshop; teacher implementation planning. |
| `07 - Collaborative Learning and Peer Thinking.pptx` | A focused deck on collaborative learning. Include this because peer learning, peer assessment, and classroom talk are a major route to making students owners of learning. | Peer learning module; discussion norms; peer feedback routines. |

Suggested extraction:

- Feedback that causes thinking rather than merely provides judgement.
- Distinctions between feedback about the task, process, and self-regulation.
- Why grades, praise, and comments can interfere with action if poorly designed.
- Student ownership: learners need to know where they are going, where they are now, and how to close the gap.
- Metacognitive routines: planning, monitoring, evaluating, and revising.
- Peer discussion routines that make student thinking visible.

Where this aligns with `The Math Academy Way`:

- Feedback and metacognition fit naturally with deliberate practice, mastery learning, and targeted remediation.
- The key shared idea is that learners need accurate information about their current state and a concrete next action.
- Retrieval and feedback are connected: retrieval tells the learner and teacher what is available from memory, then feedback guides the next practice move.

## How to Mine These Decks

For each deck, review with four questions:

1. What is the one teacher belief this deck should change?
2. What is the one classroom routine this deck should help teachers improve?
3. What is the one misconception this deck helps prevent?
4. What assessment item could show whether a teacher understood the idea?

For the manual, prefer concise explanations and examples over long slide excerpts. The manual should become a coherent teacher-facing guide, not a collage of slides.

For the live workshops, prioritize activities where teachers:

- predict student responses;
- diagnose misconceptions;
- compare weak and strong examples;
- rewrite tasks, questions, feedback, or success criteria;
- plan one small classroom implementation;
- return with evidence of what happened.

For the LMS, each module should end with scenario-based assessment rather than only recall. Teachers should have to choose, explain, or improve a classroom decision.
