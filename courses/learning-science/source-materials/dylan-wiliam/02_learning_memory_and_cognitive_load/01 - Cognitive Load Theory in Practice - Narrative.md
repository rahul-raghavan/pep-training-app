# Narrative for "Cognitive Load Theory in Practice"

## Core Thesis

Cognitive load theory is a design constraint for teaching.

It does not tell teachers everything about instruction, but it explains why some tasks create activity without learning. Students learn when their working memory is focused on the right content, with enough support to connect new information to long-term memory and not so much unnecessary load that the learning collapses.

## The Story in One Paragraph

The deck begins by defining learning as a change in long-term memory and separating learning from immediate performance. It then shows that expertise is built from organized knowledge in long-term memory, not generic thinking skill alone. From there, Wiliam explains working memory limits and cognitive load: intrinsic load comes from the complexity of what is being learned, while extraneous load comes from how instruction is designed. The practical conclusion is that teachers should reduce unnecessary load, manage necessary load, use worked examples and integrated materials, and remember that novices and experts need different kinds of support.

## The Four Acts of the Deck

### Act 1: Learning Is Not the Same as Performance

Relevant slides: 3-13

Key message:

> A student can look successful during a task without retaining the learning.

Narration:

"Before talking about cognitive load, Wiliam resets the definition of learning. Learning is a change in long-term memory. That means we cannot judge learning only by whether students complete today's task. Performance is visible now; learning is what remains later."

Use this act to challenge poor proxies for learning:

- students are busy;
- students seem engaged;
- students complete the task;
- students say they understand.

The implication:

> Instruction should be designed for durable learning, not just smooth performance.

### Act 2: Expertise Depends on Organized Knowledge

Relevant slides: 14-25

Key message:

> Experts do not just think better. They know more, and their knowledge is organized for use.

Narration:

"The chess and memory examples show why knowledge matters. Experts see meaningful patterns that novices cannot see. What looks like better general thinking is often better domain-specific knowledge in long-term memory."

This matters because teachers sometimes ask novices to behave like experts:

- solve open problems too early;
- infer patterns without enough examples;
- discover procedures without enough prior knowledge;
- monitor their own learning before they know what quality looks like.

The bridge to instruction:

> We build thinking by building usable knowledge.

### Act 3: Working Memory Is the Bottleneck

Relevant slides: 26-34

Key message:

> Working memory is limited; long-term memory is the main resource for learning.

Narration:

"Cognitive load theory starts from a simple architecture: working memory is limited, long-term memory is vast. When students face too many interacting elements at once, working memory overloads. When that happens, students may be active, but not learning the intended content."

Use the distinction:

- Intrinsic load: the complexity built into the material.
- Extraneous load: the unnecessary load created by presentation, task format, or poor sequencing.

The teacher's job is not to reduce all load. It is to:

1. reduce unnecessary load;
2. manage necessary load;
3. keep attention on the learning goal.

### Act 4: Design Instruction for Novices

Relevant slides: 35-58

Key message:

> Novices need worked examples, integrated explanations, and carefully sequenced practice.

Narration:

"The final section turns theory into design. Worked examples help novices because they reduce search. Integrated diagrams help because students do not waste working memory matching labels to parts. Dual coding helps when verbal and visual channels support one another. But extra information can become redundancy, and supports that help novices can get in the way for experts."

Practical implications:

- Use worked examples before independent problem solving.
- Fade support gradually.
- Integrate text and diagrams where students would otherwise split attention.
- Remove decorative or redundant material.
- Pre-teach vocabulary and prerequisite knowledge when it reduces intrinsic load.
- Change support as expertise grows.

## Suggested Opening Script

"Cognitive load theory is not a style of teaching. It is a warning about human cognitive architecture. Students have limited working memory. If our explanations, diagrams, tasks, or questions overload working memory, students may appear busy but fail to learn what we intended."

## Suggested Closing Script

"The practical takeaway is not 'make everything easy.' The takeaway is 'make the right things hard.' Students should think hard about the content, not about confusing instructions, split diagrams, missing vocabulary, or tasks that ask novices to search blindly. Good instruction protects working memory for learning."

## Teacher Workshop Activity

Ask teachers to bring one explanation, worksheet, slide, or task. In pairs, they identify:

1. What is the intended learning?
2. What prior knowledge does the task assume?
3. What interacting elements must be held in working memory?
4. What extraneous load can be removed?
5. Where would a worked example or partial example help?

## Link to Rosenshine

Cognitive load theory gives a learning-science explanation for several Rosenshine principles:

- Small steps reduce overload.
- Models and worked examples reduce search.
- Guided practice lets students rehearse with support.
- Checks for understanding reveal overload early.
- High success rates help teachers calibrate challenge.
- Independent practice comes after enough guidance.

The final message:

> Good teaching makes students think hard about the right things.
