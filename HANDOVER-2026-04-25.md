### Voice Audit Page Debugging
The voice audit page (`/admin/voice-audit`) is a dev-only admin tool for testing voice assessment prompts and AI rubrics. It supports recording audio or typing responses, then evaluates against the exercise rubric via Claude.

**Setup is solid** — page, API routes, and database all correct. 144 voice exercises exist across multiple programs.

**Issues found and resolved:**

1. **Placeholder API keys in `.env.local`** — Both `OPENAI_API_KEY` and `ANTHROPIC_API_KEY` were set to placeholder values. Real keys were added. The Anthropic key fix was confirmed working (typed responses evaluate correctly).

2. **Node 18 incompatibility with OpenAI SDK file uploads** — The `/api/transcribe` route uses the OpenAI SDK's `toFile` helper, which requires the global `File` class. This only exists in Node 20+. Local machine was running Node 18.20.8. **Fix: upgraded to Node 20 via nvm** (`nvm install 20 && nvm use 20`, then `rm -rf node_modules && npm install`). Voice recording + transcription now works locally.
